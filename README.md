# GlitchOS

GlitchOS is a small web based operating system project made using HTML, CSS and JavaScript. I made this as a personal project to learn more about web development and JavaScript.

## Features

* Calendar - Displayes calendar using FUllCalendar.
* Notes - A simple notes app.
* Terminal - Has commands to open apps and access feature.
* Gallery - A simple gallery.
* GlitchTV - A window for watching videos.
* Searchbar - Redirects you to google results based on your search.
* Weather - Displays your Live local weather(Requires location permission).
* Time - Displays Live time .
* IRIS/Guide - Provides a manual .
* Custom cursor 
* Draggable windows with all basic function such as minimize,fullscreen and closing.
* Glitch effects

## Built With

* HTML
* CSS
* JavaScript
* FullCalendar

Its still a work in progress and I will be adding more features in future.

## How To Run
1.Download or clone this repo.
2.Open the project folder.
3.Open index.html in your browser.
