# GlitchOS

GlitchOS is a small web based operating system project made using HTML, CSS and JavaScript. I made this as a personal project to learn more about web development and JavaScript.

## Features

* Calendar
* Notes
* Terminal
* IRIS
* Custom cursor
* Draggable windows
* Glitch effects

## Built With

* HTML
* CSS
* JavaScript
* FullCalendar

Its still a work in progress and I will be adding more features in future.
